Empty - Edi-table -Instructions

Choose what you want for the name row and you have 2 more data column boxes for each line. If you had a thumbnail file then you would have 3 more. The first entry goes in at name, the second at status and the third at description. For instance I used the english of a verb for name, the kanji for status and the pronounciation and hiragana for description. The table of course can be more dedicated by have the titles changed.

    Customising? Currently based on 5 full columns with thumbnails. Have a look at the art version and the setting with 5 columns will always prompt correctly. Important but I am a bit overwelmed with possibilites.
    Should I reveal an empty row for inserts at the start? Maybe.

The toggle buttons reveal why this is so ready for these customisation. This empty table makes it easy to see your own code results. It is set for an image but unless you put one in the file the column remains empty. Along with the above ideas this can be a dedicated customisation but you can see how it works a bit by looking.
